# 一次性计费与永久到期

管理端的单台编辑和批量编辑均支持以下选项：

- 计费周期选择「一次性」，保存为 `billing_cycle: "one_time"`。
- 到期时间勾选「永久」，保存为 `expire_date: "never"`。取消勾选会恢复本次编辑中原有的日期；重新打开永久条目后取消勾选，日期为空，需要重新填写。
- 用户主动选择「一次性」时，默认将到期时间设为永久并关闭自动续费；批量编辑同时勾选到期时间字段。仍可手动取消永久并设置具体日期。载入、重开或直接保存已有节点不应用此默认值，已有日期不会被改写。
- 一次性或永久条目不可启用自动续费；编辑、批量编辑和导入都会将 `auto_renewal` 规范为 `"0"`。

`expire_date: ""` 仍表示未设置，与永久不同。现有按月、按年等计费与日期值保持兼容，数据库使用现有文本字段，无需迁移。

## 展示、费用与提醒

内置首页卡片、详情页和管理端列表将 `"never"` 显示为「∞ 永久」。一次性价格显示为「¥99.00/一次性」等本地化文本。

一次性费用不计入月均支出。永久条目及尚未到期的一次性条目按填写的购买价计入剩余价值；已到期的一次性条目剩余价值为零。未设置到期时间仍计入缺失日期数量。永久与一次性是独立字段，永久条目填写了周期价格时仍按该周期计算月均支出。

永久条目不触发到期提醒，也不自动延长日期。带有限到期日的一次性条目仍可触发到期提醒，即使旧数据残留了自动续费标记。周期计费的月末、闰年和提前续费逻辑保持原有行为。

## 接口与主题适配

编辑、导入、导出及公共服务器接口保留 `"one_time"` 和 `"never"` 原值。第三方主题应先识别 `expire_date === "never"`，再解析日期；应将 `one_time` 的周期时长视为零，不回退成按月计费。公共接口权限和地址均未新增。

# 动态 Ping 的线上配置

`Activate dynamic Ping configuration` 通过已有 Cloudflare 部署账户读取本站原有探测地址，按实际 DNS 地址类型分组。既有中立 CDN 运营商 IPv4 地址仅在对应 IPv6 地址确实有 AAAA 记录时增加 IPv6 项；保留现有分组和目标的 ID、名称、禁用状态，仅为这些运营商 IPv4 目标补上已验证的 IPv6 地址，优先放入已有 IPv6 组。重复执行不会重复新增，也不会重新启用用户禁用的项目。

工作流默认只输出待应用方案。启用 `apply` 后，只更新 `theme_url` 和 `probe_catalog` 两个字段，固定主题 v1.2.1，并用原字段值作并发检查，防止覆盖同时发生的后台编辑。不会读取、输出或变更账户、密钥、通知设置和主题选项。配置缓存最长两分钟后刷新。

配套 Agent 采用独立四路并发探测，旧 Agent 继续接受原八路配置。上线核验须检查实际 Agent 版本、分组匹配、真实探测结果与持续资源上报；测试数据不能写入生产历史。


## 管理页面滚动

管理标题、系统状态、统计和 Tab 保持可见，内容区域独立滚动；切换 Tab 后回到该页顶部。小屏和低高度窗口压缩统计区的间距，保留可用的表单区域。服务器编辑弹窗固定头部和保存／取消按钮，仅中间表单滚动。全局设置移除旧八路输入和对应前端校验，已有旧字段及 Agent 协议继续保留，不清空数据库。

本地验证：后端完整测试与构建通过；在 1280×720、390×844、844×390 浏览器窗口操作实际滚动，管理页 body 不滚动，顶部和 Tab 坐标保持不变；编辑窗标题和底部按钮坐标保持不变。横屏内容区仍有 153px 可用高度。旧八路输入为零，移除的旧字段不参与保存按钮禁用判断。

## 提示文案修正

移除旧八路输入框后，同步将动态目录的兼容提示改为“旧版 Agent 保留已有探测配置”，避免指向已删除的“下方原有配置”。

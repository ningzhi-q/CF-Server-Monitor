# 自动更新默认值与运行控制

新增手动／自动发现节点统一写入 auto_update=1；显式写入使已有 DEFAULT 0 的数据库也能正确建号，不改写既有用户关闭状态。现有节点由用户授权的后台批量编辑单独开启。

schema 8 配置通过 update=0/1 传递后台开关，并纳入配置 MD5，复用 POST/WSS 配置通道。schema 3–7 保持原协议。Agent v1.2.0 起持久化开关、运行中启用时唤醒更新任务，关闭时停止检查；旧 Agent 必须先升级才能实现此行为。

安装与自动发现默认开启；每 6 小时检查正式版本，仍允许显式关闭。Snapshot 安装迁移到正式版后保持正式通道。
